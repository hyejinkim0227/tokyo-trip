# tokyo-trip

2026년 11월 20~23일 도쿄 여행 일정과 날짜별 지도.

- `index.html`: 여행 일정
- `map.html`: 날짜별 방문지 지도 (Leaflet 1.9.4 / OpenStreetMap)
- `map-coordinates.json`: 주소별 좌표. 국토지리원 주소 검색, 기존 여행 지도 및 Google 지도에서 확인한 매장 대표 위치.
- `tokyo-trip.kml`: 날짜별 폴더를 포함하는 Google 내 지도 가져오기용 파일
- `map-data.js`: 일정에서 생성한 날짜·주소·좌표 데이터

일정을 수정한 뒤 `python3 scripts/build-map.py`를 실행하면 지도 데이터가 갱신됩니다. 새 주소는 `map-coordinates.json`에 좌표를 추가해야 합니다. 좌표가 없는 방문지가 있으면 빌드가 실패하므로 누락을 확인할 수 있습니다. 같은 주소·건물은 하나의 핀에서 여러 장소를 표시합니다.

2026-11-12: AFURI 하라주쿠·쿠로긴·야마초·마루타케·HARBS·긴자 웨스트 두 지점·시로이치를 반영하고, 스시쿠니·마루시치·이타도리 후보를 제외했습니다. 사이트 지도는 저장소 안의 일정 데이터로 관리합니다.
